# InsureCow

## 🚀 Overview
**InsureCow** is a comprehensive **Insurance Management and Farm Management System** that offers a **360° technology-powered cattle insurance and wellbeing monitoring platform**. It bridges the gap between farmers, SMEs, NGOs, insurers, and financial institutions by increasing access to finance, technology, and information.

> **Note:** The current version is deprecated and no longer maintained or available for showcase.

## 🏗️ Technology Stack

### **Backend:**
- Laravel Framework (v8)

### **Database:**
- MySQL

## 🔥 Key Features
### 🏢 Super Admin
- Dashboard Overview:
    - Number of registered companies
    - Ability to change user access permissions
    - View and register farmers
    - Manage farm and cattle registrations
    - View total farms and animals
- Farmer & Company Management:
    - Register farmers and companies
    - View registered companies along with associated farmers
    - Manage permissions for farmers and companies
- CMS System:
    - Modify front-page content

### 🌾 Agritech Company
- View registered farmers and their cattle
- Manage permissions for farmers
- View insured animal lists
- Track pending insurance requests and due amounts
- Monitor claims submitted by farmers
- Access animal insurance transactions

### 🏦 Insurance Company
- View pending insurance requests and due payments
- Manage insured animals
- Track income from insurance policies
- Create and manage package policies
- Monitor claimed cattle
- View total insurance transactions

### 🚜 Farmer
- Access Dashboard:
    - View personal information
    - Manage farm and cattle registrations
    - Check verification reports
- Insurance Management:
    - Insure animals
    - Monitor insurance requests
    - Verify cattle ownership
- Profile & Security:
    - Update profile and address
    - Change password

### 🏠 Farm Management
- Track financial health:
    - View total income and expenses
    - Calculate profit/loss status
- Manage farm data:
    - Register and track animals
    - Monitor animal health, feeding, and breeding
    - Export farm data (Excel format)
- Budgeting and forecasting tools
- Asset and expense management
